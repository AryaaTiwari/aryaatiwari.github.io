# Aryaa Tiwari — Level Up Portfolio

A game-inspired professional portfolio for GitHub Pages.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — scroll progress and reveal animations

## Publish on GitHub Pages

1. Create a repository named `AryaaTiwari.github.io` (or use an existing GitHub Pages repository).
2. Upload these three files to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. Save and open the Pages URL.

## Before publishing

Replace the placeholder email in `index.html` with Aryaa's preferred email address.

The site intentionally avoids inventing exact ISRO certification names, dates, school dates beyond the details supplied, or exact Class X rank. Those can be added once the certificates/details are available.
